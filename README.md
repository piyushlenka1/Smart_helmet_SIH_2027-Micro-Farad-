Smart IoT Helmet

A Smart IoT-based Helmet developed for the Smart India Hackathon (SIH) to enhance two-wheeler rider safety through real-time monitoring, accident detection, GPS tracking, and emergency communication.

Features
Accident and impact detection
GPS-based location tracking
Emergency alert system
Real-time sensor monitoring
IoT-based communication
Helmet safety monitoring
Technologies
ESP32 / Arduino
MPU6050 and other sensors
GPS Module
GSM / Wi-Fi
IoT and Cloud Services
Embedded C/C++
Working

The helmet continuously monitors sensor data to identify abnormal motion or potential accidents. When an accident is detected, the system obtains the rider's location through GPS and sends an emergency alert to predefined contacts.

SIH Project

This project was developed as a solution for the Smart India Hackathon, focusing on the use of IoT and embedded systems to improve road safety and emergency response for two-wheeler riders.
